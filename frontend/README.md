# Vastora Tech — Frontend Application

High-performance digital engineering agency web platform built with **Next.js 14**, **TypeScript**, and modern SCSS architecture.

---

## Technical Stack

- **Framework**: Next.js 14 (App Router & Pages Router hybrid architecture)
- **Language**: TypeScript 5
- **Styling**: SCSS, Bootstrap 5, custom agency motion modules
- **State Management & Forms**: React Hook Form, Yup
- **Icons & Motion**: Lucide React, Swiper, React CountUp, WOW.js

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 4. Build for Production
```bash
npm run build
npm start
```

---

## Application Structure

- `src/app/` — Next.js App Router pages and metadata definitions
- `src/components/` — Modular UI components (Hero, Capabilities, Tech Ecosystem, Portfolio, etc.)
- `src/layout/` — Global headers, footers, and wrapper layouts
- `src/styles/` — SCSS stylesheets and responsive design systems
- `src/data/` — Static content models, project cases, service catalogs
- `public/` — Static assets (optimized images, SVGs, favicon manifests)
