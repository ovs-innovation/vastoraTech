# Vastora Tech — Admin Management Dashboard

Production administration and operations console for **Vastora Tech** built with **React**, **Vite**, **Tailwind CSS**, and **Windmill React UI**.

---

## Technical Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS & Windmill React UI
- **Routing**: React Router DOM 6
- **State & Data Fetching**: Redux Toolkit & React Query
- **Charts & Metrics**: Chart.js / React-Chartjs-2
- **Icons**: React Icons (Fi, Io5, Bi, etc.)

---

## Key Capabilities

- **Lead Intake Management**: Review incoming agency consultations, project briefs, and client leads.
- **Blog & Editorial Studio**: Author and publish agency technical blogs, SEO content, and case studies.
- **Client Demos & Inquiries**: Track demo bookings and service requests.
- **Invoicing & Statements**: Review commercial accounts and transaction histories.
- **Role-Based Access Control**: Staff and administrator security tiers.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Ensure `VITE_APP_API_BASE_URL` points to your active backend API.

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
